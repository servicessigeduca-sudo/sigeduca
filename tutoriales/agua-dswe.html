Agua superficial con DSWE (Jones, 2019) en Google Earth Engine

intermedioLección 4 de 430 minGoogle Earth Engine

Clasifica el agua de cada año con el método DSWE, calcula su área, grafica cómo cambia y crea una animación GIF de la serie de Landsat.

Introducción #

En el curso básico detectamos agua con un índice y un umbral. Eso funciona bien en lagos y ríos abiertos, pero falla en las orillas, en los humedales con vegetación y en los píxeles que solo están cubiertos de agua en parte. DSWE (Dynamic Surface Water Extent) aborda ese problema combinando cinco pruebas espectrales en lugar de una.

En esta lección aplicaremos DSWE a cada año de la serie de Landsat. Con la máscara de agua de cada año mediremos cuántos kilómetros cuadrados de agua hay, graficaremos cómo cambian y crearemos una animación GIF de la serie. Es un solo script, de la sección 0 a la 11.

Objetivos #

  • Entender las cinco pruebas de DSWE y las clases que producen.
  • Cargar la función DSWE desde un módulo y aplicarla a una serie anual de Landsat.
  • Calcular y graficar el área de agua de cada año.
  • Crear un GIF de la serie con el año escrito en cada cuadro.
  • Exportar la máscara de agua de cada año.

Recursos #

  • Producto DSWE de Landsat Colección 2 (USGS)
  • Descripción del algoritmo DSWE, LSDS-2084 (USGS, PDF)
  • Jones (2019), revisión de las pruebas de agua parcial de DSWE
  • ee.Image.pixelArea()
  • ee.ImageCollection.getVideoThumbURL()

De dónde viene DSWE #

DSWE fue desarrollado por John W. Jones, del Servicio Geológico de Estados Unidos (USGS). La primera versión (Jones, 2015) nació para seguir el agua en los humedales de los Everglades, en Florida, donde buena parte de la inundación ocurre bajo la vegetación y es difícil de ver desde el satélite. Jones comparó sus resultados con los niveles de agua que mide en campo la red EDEN (Everglades Depth Estimation Network). En 2019 publicó una revisión de las dos pruebas de agua parcial, que mejoró la detección de píxeles cubiertos solo en parte por agua (Jones, 2019).

El USGS distribuye DSWE como producto oficial de Landsat, pero solo para Estados Unidos. Para cualquier otro lugar, como Colombia, hay que calcularlo. Nuestro módulo parte de la implementación de RivWidthCloud, un algoritmo para medir el ancho de los ríos publicado por Yang, Pavelsky, Allen y Donchyts (2020), adaptada a Landsat Colección 2.

Las cinco pruebas #

DSWE trabaja con reflectancia de superficie, de 0 a 1, y usa cinco valores: MNDWI, NDVI, MBSRV (verde + rojo), MBSRN (NIR + SWIR1) y AWEsh. AWEsh es la versión para zonas con sombras del índice de Feyisa et al. (2014) que vimos en el curso básico.

PruebaCondiciónQué busca
1MNDWI > 0,124Agua abierta según el MNDWI
2MBSRV > MBSRNEl visible (verde + rojo) supera al infrarrojo (NIR + SWIR1), algo típico del agua
3AWEsh > 0Agua según el AWEsh
4MNDWI > −0,44, SWIR1 < 0,09, NIR < 0,15 y NDVI < 0,7Agua parcial, con criterio conservador
5MNDWI > −0,5, Azul < 0,1, SWIR1 < 0,3, SWIR2 < 0,1 y NIR < 0,25Agua parcial, con criterio agresivo

Las tres primeras pruebas buscan agua abierta. Las dos últimas buscan agua parcial y son las que revisó Jones en 2019: la prueba 4 es estricta para no confundir el agua con bosques oscuros, y la 5 es más permisiva para no perder el agua que hay bajo pastos y juncos.

De las pruebas a las clases #

Cada prueba aporta un dígito a un código de cinco cifras, ordenado de la prueba 5 a la 1. Por ejemplo, 00111 significa que se cumplieron las pruebas 1, 2 y 3. El USGS asigna cada uno de los 32 códigos posibles a una clase:

ClaseNombreCuándo se asigna
0No aguaSe cumple una prueba o ninguna, salvo si la única es la 5
1Agua, confianza altaSe cumplen cuatro o cinco pruebas
2Agua, confianza moderadaSe cumplen tres pruebas
3Agua parcial, conservadoraSolo se cumplen las pruebas 4 y 5 (código 11000)
4Agua parcial, agresivaSe cumplen dos pruebas, salvo 4 y 5 juntas, o solo la 5

En la práctica, las clases 1 y 2 son agua abierta, y las 3 y 4 son zonas que pueden estar inundadas en parte, como humedales u orillas. La función ClassifyWaterJones2019() del módulo devuelve una máscara de agua (waterMask) con las clases 1 y 2.

DSWE se diseñó para escenas individuales. Al aplicarlo a una mediana anual obtenemos el agua típica del año, no la máxima: un desborde que duró dos semanas puede no aparecer. Si te interesa la temporada de lluvias, ajusta startMonth y endMonth para que la mediana use solo esos meses.

Secciones 0 a 5: Construir la serie anual #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Las secciones 0 a 5 son las mismas de Series de tiempo con Landsat: funciones, bandas, unión de Landsat 4 a 9, parámetros, filtros y medianas anuales. Esta vez la serie empieza en 2000.

///////////////////////////////////////////////////////////////////////////////////
// 0 → CREAR FUNCIONES PRINCIPALES
///////////////////////////////////////////////////////////////////////////////////

// 0.1 → Función de factor de escala
function scaler (img) {
  var optical = img.select("SR_B.").multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select("ST_B.*").multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// 0.2 → Función de máscara de nubes
function mask_clouds (img) {
  // Banda de calidad QA_PIXEL (renombrada como BQA)
  var qa = img.select('BQA');
  // Bits de QA_PIXEL en Landsat Colección 2
  var cirrus = (1 << 2);              // bit 2: cirros
  var cloudsBitMask = (1 << 3);       // bit 3: nubes
  var cloudShadowBitMask = (1 << 4);  // bit 4: sombras de nubes
  var snow = (1 << 5);                // bit 5: nieve
  // Todos los bits deben estar en cero (condiciones despejadas)
  var mask = qa.bitwiseAnd(cloudShadowBitMask).eq(0)
    .and(qa.bitwiseAnd(cloudsBitMask).eq(0))
    .and(qa.bitwiseAnd(cirrus).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

El módulo de Jones (2019) #

Las pruebas y la tabla de clases están en el módulo público users/sigeduca/routines:Indexes/Jones_2019, que el script carga con require(). No tienes que copiarlo; lo mostramos para que veas cómo funciona. Cada prueba devuelve una imagen de ceros y unos. Al multiplicarlas por 1, 10, 100, 1000 y 10 000 y sumarlas obtenemos el código de cinco cifras de cada píxel; los ceros a la izquierda desaparecen, así que 00111 queda como 111. Después, cada grupo de códigos se convierte en su clase.

Agua oscura y valores negativos. El factor de escala de la Colección 2 resta 0,2, así que en el mar o en lagos profundos algunas bandas quedan un poco por debajo de 0. normalizedDifference() enmascara cualquier píxel con un valor negativo, y sin corrección esas zonas quedarían sin clasificar, sobre todo en las costas. Por eso, al inicio de Dswe(), llevamos a 0 las bandas negativas con max(0).

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
//// Main references 
///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

//[3] * Jones, J. W. (2019). Improved automated detection of subpixel-scale inundation—Revised dynamic surface water extent (DSWE) partial surface water tests. Remote Sensing, 11(4), 374.


/*This code is code was retrieved from 
github.com/seanyx/RivWidthCloudPaper/blob/master/RivWidthCloud_JavaScript/functions_Landsat578/functions_waterClassification_Jones2019.js

water test functions for determing DSWE

ADAPTACIÓN A LANDSAT COLECCIÓN 2:
El original usaba Landsat Colección 1 SR, guardada x 10 000, por eso los umbrales de las
pruebas 4 y 5 eran 900, 1500, 1000, 3000 y 2500. Aquí la imagen llega escalada con scaler()
(reflectancia de 0 a 1), así que esos umbrales pasan a 0.09, 0.15, 0.1, 0.3 y 0.25,
los mismos que publica el USGS para la Colección 2.
Además, las bandas negativas se llevan a 0 al inicio de Dswe(), porque normalizedDifference()
enmascara los píxeles negativos y el agua oscura de las costas quedaba sin clasificar.
*/

// water test functions for determing DSWE
var Mndwi = function(image) {
  return(image.normalizedDifference(['Green', 'Swir1']).rename('mndwi'));
};
var Mbsrv = function(image) {
  return(image.select(['Green']).add(image.select(['Red'])).rename('mbsrv'));
};
var Mbsrn = function(image) {
  return(image.select(['Nir']).add(image.select(['Swir1'])).rename('mbsrn'));
};
var Ndvi = function(image) {
  return(image.normalizedDifference(['Nir', 'Red']).rename('ndvi'));
};
var Awesh = function(image) {
  return(image
  .expression('Blue + 2.5 * Green + (-1.5) * mbsrn + (-0.25) * Swir2', {
    'Blue': image.select(['Blue']),
    'Green': image.select(['Green']),
    'mbsrn': Mbsrn(image).select(['mbsrn']),
    'Swir2': image.select(['Swir2'])
  }));
};

var Dswe = function(i) {
  // En agua oscura (mar, lagos profundos) la reflectancia escalada puede ser negativa,
  // y normalizedDifference() enmascara esos píxeles. Se usa 0 como mínimo.
  i = i.select(['Blue', 'Green', 'Red', 'Nir', 'Swir1', 'Swir2']).max(0);
  var mndwi = Mndwi(i);
  var mbsrv = Mbsrv(i);
  var mbsrn = Mbsrn(i);
  var awesh = Awesh(i);
  var swir1 = i.select(['Swir1']);
  var nir = i.select(['Nir']);
  var ndvi = Ndvi(i);
  var blue = i.select(['Blue']);
  var swir2 = i.select(['Swir2']);
  
  
  var t1 = mndwi.gt(0.124);
  var t2 = mbsrv.gt(mbsrn);
  var t3 = awesh.gt(0);
  var t4 = mndwi.gt(-0.44)
  .and(swir1.lt(0.09))   // original: 900
  .and(nir.lt(0.15))     // original: 1500
  .and(ndvi.lt(0.7));
  var t5 = mndwi.gt(-0.5)
  .and(blue.lt(0.1))     // original: 1000
  .and(swir1.lt(0.3))    // original: 3000
  .and(swir2.lt(0.1))    // original: 1000
  .and(nir.lt(0.25));    // original: 2500
  
  var t = t1.add(t2.multiply(10)).add(t3.multiply(100)).add(t4.multiply(1000)).add(t5.multiply(10000));
  
  var noWater = t.eq(0)
  .or(t.eq(1))
  .or(t.eq(10))
  .or(t.eq(100))
  .or(t.eq(1000));
  var hWater = t.eq(1111)
  .or(t.eq(10111))
  .or(t.eq(11011))
  .or(t.eq(11101))
  .or(t.eq(11110))
  .or(t.eq(11111));
  var mWater = t.eq(111)
  .or(t.eq(1011))
  .or(t.eq(1101))
  .or(t.eq(1110))
  .or(t.eq(10011))
  .or(t.eq(10101))
  .or(t.eq(10110))
  .or(t.eq(11001))
  .or(t.eq(11010))
  .or(t.eq(11100));
  var pWetland = t.eq(11000);
  var lWater = t.eq(11)
  .or(t.eq(101))
  .or(t.eq(110))
  .or(t.eq(1001))
  .or(t.eq(1010))
  .or(t.eq(1100))
  .or(t.eq(10000))
  .or(t.eq(10001))
  .or(t.eq(10010))
  .or(t.eq(10100));
  
  var iDswe = noWater.multiply(0)
  .add(hWater.multiply(1))
  .add(mWater.multiply(2))
  .add(pWetland.multiply(3))
  .add(lWater.multiply(4));
  
  return(iDswe.rename('dswe'));
};

exports.ClassifyWaterJones2019 = function(img) {
  var dswe = Dswe(img);
  var waterMask = dswe.eq(1).or(dswe.eq(2)).rename(['waterMask']);
  return(waterMask);
};

Ojo con los umbrales si usas otro código. En RivWidthCloud, las pruebas 4 y 5 usan valores como 900, 1500 o 3000, porque se escribieron para Landsat Colección 1, que guardaba la reflectancia multiplicada por 10 000. Nuestras imágenes ya pasaron por scaler() y están entre 0 y 1, así que esos umbrales equivalen a 0,09, 0,15 y 0,3, los mismos que publica el USGS para la Colección 2. Si se dejan los valores de la Colección 1 con datos escalados, las condiciones de reflectancia se cumplen siempre, y DSWE marca como agua más píxeles de los que debería.

Sección 6: Aplicar DSWE a la serie #

Jones() agrega la máscara de agua como banda nueva, así que cada año conserva su reflectancia y su año. Después seleccionamos solo waterMask y guardamos esas máscaras en masked.

///////////////////////////////////////////////////////////////////////////////////
// 6 → APLICAR DSWE JONES (2019)
///////////////////////////////////////////////////////////////////////////////////

var x = require('users/sigeduca/routines:Indexes/Jones_2019'); // MÓDULO DE JONES

// Crear función Jones (DSWE)
function Jones (image){
  var river = x.ClassifyWaterJones2019(image);
  return image.addBands(river);
}

var water_jones_2019 = colmeans.map(Jones);
var masked = water_jones_2019.select("waterMask"); // colección de máscaras de agua

print("Máscara de agua, Jones (2019)", masked);

Sección 7: Calcular el área de agua #

Un mapa de agua por año es útil, pero la pregunta que suele importar es más directa: ¿hay más o menos agua que antes? ee.Image.pixelArea() da el área de cada píxel en metros cuadrados, y la dividimos entre un millón para pasarla a km². Multiplicada por la máscara de agua, solo suman los píxeles de agua. reduceRegion() suma ese valor dentro del AOI, y el resultado se guarda como propiedad water_area de cada imagen. Con bestEffort: true, Earth Engine aumenta el tamaño de píxel si el AOI es muy grande, para que el cálculo no falle.

///////////////////////////////////////////////////////////////////////////////////
// 7 → CALCULAR ÁREA DE CUERPOS DE AGUA
///////////////////////////////////////////////////////////////////////////////////

// Función para calcular el área de agua de cada imagen
function water_area (img){
  var water = img.eq(1);
  var area = ee.Image.pixelArea();
  var waterArea = water.multiply(area).divide(1000000).rename('water_area');
  var stats = waterArea.reduceRegion({reducer: ee.Reducer.sum(), geometry: AOI, scale: 30,
                                      bestEffort: true, maxPixels: 10000000000});
  return img.set(stats).copyProperties(img);
}

var water_area_c = masked.map(water_area);
var year_si = ee.Array(masked.aggregate_array('year'));
var wa_y = ee.Array(water_area_c.aggregate_array('water_area'));

Sección 10: Crear la animación GIF #

Un gráfico resume el cambio en números, pero una animación lo muestra. Cada cuadro del GIF debe ser una imagen RGB de 8 bits, y visualize() entrega justo eso. El año lo escribe el paquete text de Gennadii Donchyts, muy usado en la comunidad de Earth Engine y disponible para todos.

gifParams fija el tamaño máximo en píxeles (dimensions) y la velocidad (framesPerSecond). En annotations indicamos que el texto vaya arriba y que lo tome de la propiedad año. El tamaño de la letra depende de la escala del mapa cuando ejecutas el script; si sale muy pequeña o muy grande, cambia el 2 de Map.getScale() * 2.

makeGifAnimation() recibe una colección, unos parámetros de visualización y un nombre. Convierte cada imagen en un cuadro, escribe el año y une la serie con su versión invertida para que la animación vaya y vuelva sin cortes. La llamamos dos veces: el falso color SWIR1-NIR-Rojo muestra el agua casi negra, la vegetación verde y el suelo desnudo en tonos rosados; la máscara de agua muestra solo el agua, en azul.

///////////////////////////////////////////////////////////////////////////////////
// 10 → CREACIÓN DE ANIMACIÓN CON FORMATO GIF
///////////////////////////////////////////////////////////////////////////////////

// Parámetros:
//   collection → ImageCollection a animar
//   visArgs    → argumentos de visualización (bandas, min, max, palette, etc.)
//   label      → nombre para identificar la animación en la consola

var text = require('users/gena/packages:text');

var gifParams = {
  'region': AOI,
  'dimensions': 800,
  'crs': 'EPSG:4326',
  'framesPerSecond': 6
};

var annotations = [{
  position: 'top',
  offset: '5%',
  margin: '5%',
  property: 'año',
  scale: Map.getScale() * 2
}];

function makeGifAnimation(collection, visArgs, label) {

  // Convertir cada imagen a visualización RGB y añadir la etiqueta del año

///////////////////////////////////////////////////////////////////////////////////
// 0 → CREAR FUNCIONES PRINCIPALES
///////////////////////////////////////////////////////////////////////////////////

// 0.1 → Función de factor de escala
function scaler (img) {
  var optical = img.select("SR_B.").multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select("ST_B.*").multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// 0.2 → Función de máscara de nubes
function mask_clouds (img) {
  // Banda de calidad QA_PIXEL (renombrada como BQA)
  var qa = img.select('BQA');
  // Bits de QA_PIXEL en Landsat Colección 2
  var cirrus = (1 << 2);              // bit 2: cirros
  var cloudsBitMask = (1 << 3);       // bit 3: nubes
  var cloudShadowBitMask = (1 << 4);  // bit 4: sombras de nubes
  var snow = (1 << 5);                // bit 5: nieve
  // Todos los bits deben estar en cero (condiciones despejadas)
  var mask = qa.bitwiseAnd(cloudShadowBitMask).eq(0)
    .and(qa.bitwiseAnd(cloudsBitMask).eq(0))
    .and(qa.bitwiseAnd(cirrus).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

// Función para calcular el área de agua de cada imagen
function water_area (img){
  var water = img.eq(1);
  var area = ee.Image.pixelArea();
  var waterArea = water.multiply(area).divide(1000000).rename('water_area');
  var stats = waterArea.reduceRegion({reducer: ee.Reducer.sum(), geometry: AOI, scale: 30,
                                      bestEffort: true, maxPixels: 10000000000});
  return img.set(stats).copyProperties(img);
}

Conclusiones #

Con un solo script recorriste todo el análisis: construiste la serie, clasificaste el agua de cada año con DSWE, mediste su área y la mostraste en una animación. Antes de sacar conclusiones, compara siempre la misma temporada y revisa los años con huecos. La función makeGifAnimation() sirve para cualquier colección, así que puedes usarla también con la serie de Sentinel-2 o con los índices de vegetación.

Si trabajas con Sentinel-2, el proyecto OPERA del JPL de la NASA publica DSWx-HLS, un producto basado en DSWE que combina imágenes de Landsat y Sentinel-2. También está en el catálogo de Earth Engine como OPERA/DSWX/L3_V1/HLS.
