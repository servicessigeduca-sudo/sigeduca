Introducción #

Un mapa de agua por año es útil, pero la pregunta que suele importar es más directa: ¿hay más o menos agua que antes? En esta lección convertiremos cada máscara de DSWE en un área en kilómetros cuadrados y haremos un gráfico de su evolución.

Este tipo de análisis sirve para seguir embalses durante una sequía, ciénagas que se sedimentan o ríos que cambian de cauce.

Objetivos #

  • Calcular el área de agua de cada año con ee.Image.pixelArea().
  • Sumar el área dentro del AOI con reduceRegion().
  • Graficar la evolución del área de agua.
  • Visualizar y exportar las máscaras de cada año.

Recursos #

  • ee.Image.pixelArea()
  • ee.Image.reduceRegion()
  • ui.Chart.array.values()

El problema de los huecos #

Las nubes que la mediana no logró quitar dejan píxeles sin datos, y en los años de Landsat 7 aparecen además sus franjas vacías. Esos píxeles no cuentan ni como agua ni como tierra. Si un año tiene muchos huecos, su área de agua saldrá más baja de lo real. Antes de interpretar una caída en el gráfico, activa la máscara de ese año en el mapa y revisa si tiene zonas vacías.

// 0.1 → Función de factor de escala
function scaler (img) {
  var optical = img.select("SR_B.").multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select("ST_B.*").multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// 0.2 → Función de máscara de nubes
function mask_clouds (img) {
  // Banda de calidad QA_PIXEL (renombrada como BQA)
  var qa = img.select('BQA');
  // Bits de QA_PIXEL en Landsat Colección 2
  var cirrus = (1 << 2);              // bit 2: cirros
  var cloudsBitMask = (1 << 3);       // bit 3: nubes
  var cloudShadowBitMask = (1 << 4);  // bit 4: sombras de nubes
  var snow = (1 << 5);                // bit 5: nieve
  // Todos los bits deben estar en cero (condiciones despejadas)
  var mask = qa.bitwiseAnd(cloudShadowBitMask).eq(0)
    .and(qa.bitwiseAnd(cloudsBitMask).eq(0))
    .and(qa.bitwiseAnd(cirrus).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

Sección 7: Calcular el área de agua #

ee.Image.pixelArea() da el área de cada píxel en metros cuadrados, y la dividimos entre un millón para pasarla a km². Multiplicada por la máscara de agua, solo suman los píxeles de agua. reduceRegion() suma ese valor dentro del AOI, y el resultado se guarda como propiedad water_area de cada imagen. Con bestEffort: true, Earth Engine aumenta el tamaño de píxel si el AOI es muy grande, para que el cálculo no falle.

///////////////////////////////////////////////////////////////////////////////////
// 7 → CALCULAR ÁREA DE CUERPOS DE AGUA
///////////////////////////////////////////////////////////////////////////////////

// Función para calcular el área de agua de cada imagen
function water_area (img){
  var water = img.eq(1);
  var area = ee.Image.pixelArea();
  var waterArea = water.multiply(area).divide(1000000).rename('water_area');
  var stats = waterArea.reduceRegion({reducer: ee.Reducer.sum(), geometry: AOI, scale: 30,
                                      bestEffort: true, maxPixels: 10000000000});
  return img.set(stats).copyProperties(img);
}

var water_area_c = masked.map(water_area);
var year_si = ee.Array(masked.aggregate_array('year'));
var wa_y = ee.Array(water_area_c.aggregate_array('water_area'));
