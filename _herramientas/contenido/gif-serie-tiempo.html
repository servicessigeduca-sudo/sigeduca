Introducción #

Un gráfico resume el cambio en números, pero una animación lo muestra. Ver cuadro a cuadro cómo una ciénaga se encoge o un río cambia de cauce es la forma más rápida de explicar un resultado en una clase, un informe o una red social.

En esta lección agregamos al script de la lección anterior dos GIF: uno en falso color y otro con la máscara de agua de DSWE, con el año escrito en cada cuadro.

Objetivos #

  • Convertir cada imagen de una colección en un cuadro RGB con visualize().
  • Escribir el año en cada cuadro con un paquete de texto.
  • Generar un GIF con getVideoThumbURL() y verlo en la consola.
  • Reutilizar la misma función con distintas visualizaciones.

Recursos #

  • ee.ImageCollection.getVideoThumbURL()
  • Visualización de colecciones de imágenes (guía de Earth Engine)

Cómo se arma un GIF en Earth Engine #

  • Cada cuadro debe ser una imagen RGB de 8 bits. visualize() aplica los parámetros de visualización y entrega justo eso.
  • El año lo dibuja el paquete text de Gennadii Donchyts, muy usado en la comunidad de Earth Engine. Se carga con require() y está disponible para todos los usuarios.
  • getVideoThumbURL() devuelve un enlace al GIF, y ui.Thumbnail lo muestra en la consola.

Secciones 0 a 9: Serie, DSWE y área #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Las secciones 0 a 9 son las mismas de Área de agua por año: la serie anual, la máscara de agua de Jones (2019), el área de agua con su gráfico y la visualización en el mapa. Puedes copiarlas de esa lección o tomarlas del código completo al final de esta página.

Sobre el módulo. require() carga funciones guardadas en otro script del Code Editor, en este caso users/sigeduca/routines:Indexes/Jones_2019. Si al ejecutar aparece un error de acceso, crea un script nuevo en tu propio repositorio, pega el código del módulo que mostramos aquí, guárdalo como Jones_2019 y cambia la ruta de require() por la tuya, por ejemplo users/TU_USUARIO/TU_REPOSITORIO:Jones_2019.

Sección 10: Crear la animación #

gifParams fija el tamaño máximo en píxeles (dimensions) y la velocidad (framesPerSecond). En annotations indicamos que el texto vaya arriba y que lo tome de la propiedad año. El tamaño de la letra depende de la escala del mapa cuando ejecutas el script; si sale muy pequeña o muy grande, cambia el 2 de Map.getScale() * 2.

makeGifAnimation() recibe una colección, unos parámetros de visualización y un nombre. Convierte cada imagen en un cuadro, escribe el año y une la serie con su versión invertida para que la animación vaya y vuelva sin cortes. La llamamos dos veces: el falso color SWIR1-NIR-Rojo muestra el agua casi negra, la vegetación verde y el suelo desnudo en tonos rosados; la máscara de agua muestra solo el agua, en azul.

///////////////////////////////////////////////////////////////////////////////////
// 10 → CREACIÓN DE ANIMACIÓN CON FORMATO GIF
///////////////////////////////////////////////////////////////////////////////////

// Parámetros:
//   collection → ImageCollection a animar
//   visArgs    → argumentos de visualización (bandas, min, max, palette, etc.)
//   label      → nombre para identificar la animación en la consola

var text = require('users/gena/packages:text');

var gifParams = {
  'region': AOI,
  'dimensions': 800,
  'crs': 'EPSG:4326',
  'framesPerSecond': 6
};

var annotations = [{
  position: 'top',
  offset: '5%',
  margin: '5%',
  property: 'año',
  scale: Map.getScale() * 2
}];

function makeGifAnimation(collection, visArgs, label) {

  // Convertir cada imagen a visualización RGB y añadir la etiqueta del año
  var visFun = function(img) {
    var y = ee.Number(img.get('year')).toInt();
    return img.visualize(visArgs).set('año', ee.String(y));
  };

  // Escribir el año sobre cada imagen
  var text_f = function(img) {
    return text.annotateImage(img, {}, AOI, annotations)
               .copyProperties(img, img.propertyNames());
  };

  // Aplicar visualización y anotación, y construir la animación (ida y vuelta)
  var animated = collection.map(visFun).map(text_f);
  var basicAnimation = animated.merge(animated.sort('año', false));

  // Mostrar en la consola
  print('GIF URL → ' + label, basicAnimation.getVideoThumbURL(gifParams));
  print('Animación → ' + label, ui.Thumbnail(basicAnimation, gifParams));

  return basicAnimation;
}

// Animación en falso color (Swir1, Nir, Red)
var visArgs_RGB = {bands: 'Swir1,Nir,Red', min: 0.0125, max: 0.41448, gamma: 1};
var anim_RGB = makeGifAnimation(ee.ImageCollection(img_medians), visArgs_RGB, 'RGB Landsat');

// Animación de la máscara de agua (Jones, 2019)
var visArgs_WATER = {bands: 'waterMask', opacity: 1, palette: ['0c0c0c', '0400ff']};
var anim_WATER = makeGifAnimation(masked, visArgs_WATER, 'Water Mask Jones 2019');

Para descargar el GIF, haz clic en el enlace que aparece en la consola y guárdalo desde el navegador. Si Earth Engine responde que la animación es demasiado grande, reduce dimensions o el tamaño del AOI.

Código completo #

Este es el script completo. Cópialo, pégalo en el Code Editor, dibuja tu AOI y presiona Run.

///////////////////////////////////////////////////////////////////////////////////
// 0 → CREAR FUNCIONES PRINCIPALES
///////////////////////////////////////////////////////////////////////////////////

// 0.1 → Función de factor de escala
function scaler (img) {
  var optical = img.select("SR_B.").multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select("ST_B.*").multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// 0.2 → Función de máscara de nubes
function mask_clouds (img) {
  // Banda de calidad QA_PIXEL (renombrada como BQA)
  var qa = img.select('BQA');
  // Bits de QA_PIXEL en Landsat Colección 2
  var cirrus = (1 << 2);              // bit 2: cirros
  var cloudsBitMask = (1 << 3);       // bit 3: nubes
  var cloudShadowBitMask = (1 << 4);  // bit 4: sombras de nubes
  var snow = (1 << 5);                // bit 5: nieve
  // Todos los bits deben estar en cero (condiciones despejadas)
  var mask = qa.bitwiseAnd(cloudShadowBitMask).eq(0)
    .and(qa.bitwiseAnd(cloudsBitMask).eq(0))
    .and(qa.bitwiseAnd(cirrus).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

// 4 → APLICAR FILTROS A LA COLECCIÓN FUSIONADA
///////////////////////////////////////////////////////////////////////////////////

var filtered = merged.filterDate(startYear + '-01-01', endYear + '-12-31')
                     .filter(ee.Filter.lte('CLOUD_COVER_LAND', cloudcover))
                     .filter(ee.Filter.calendarRange(startMonth, endMonth, 'month'))
                     .sort('system:time_start', false)
                     .filterBounds(AOI);

print("Imágenes disponibles para la zona de estudio (Landsat 4, 5, 7, 8 y 9)", filtered);

// 5 → CALCULAR MEDIANAS ANUALES
///////////////////////////////////////////////////////////////////////////////////

var years = ee.List.sequence(startYear, endYear);

function yearly_medians(year) {
  var start = ee.Date.fromYMD(year, 1, 1);
  var end = start.advance(1, 'year');
  var L = filtered.map(mask_clouds);
  var image = L.filterDate(start, end).median().clip(AOI).toFloat();
  return image.set('year', year);
}

// Generar medianas por año
var img_medians = years.map(yearly_medians);

// Remover imágenes vacías
img_medians = img_medians.map(function(ele) {
  var count = ee.Image(ele).bandNames().size();
  return ee.Algorithms.If(count.gt(0), ele, 0);
}).flatten();
img_medians = img_medians.removeAll([0]);

// Colección de medianas anuales
var colmeans = ee.ImageCollection(img_medians);
var años = ee.Array(colmeans.aggregate_array('year'));

// 7 → CALCULAR ÁREA DE CUERPOS DE AGUA

// Función para calcular el área de agua de cada imagen
function water_area (img){
  var water = img.eq(1);
  var area = ee.Image.pixelArea();
  var waterArea = water.multiply(area).divide(1000000).rename('water_area');
  var stats = waterArea.reduceRegion({reducer: ee.Reducer.sum(), geometry: AOI, scale: 30,
                                      bestEffort: true, maxPixels: 10000000000});
  return img.set(stats).copyProperties(img);
}

var water_area_c = masked.map(water_area);
var year_si = ee.Array(masked.aggregate_array('year'));
var wa_y = ee.Array(water_area_c.aggregate_array('water_area'));

Conclusiones #

Con esto completas el recorrido de series de tiempo: construiste la serie, calculaste índices y máscaras de agua para cada año, mediste su evolución y ahora puedes mostrarla en una animación. La función makeGifAnimation() sirve para cualquier colección, así que puedes usarla también con la serie de Sentinel-2 o con los índices de vegetación.
