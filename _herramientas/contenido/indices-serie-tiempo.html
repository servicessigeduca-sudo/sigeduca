Introducción #

Un índice calculado en una sola fecha muestra cómo está la vegetación o el agua en ese momento. Calculado año tras año, muestra tendencias: una zona que se deforesta, un humedal que se seca o un cultivo que se expande.

En esta lección aplicaremos una función de índices a toda la serie anual de Landsat con map(). Después haremos un gráfico de su evolución y un mapa del cambio entre el primer y el último año.

Objetivos #

  • Aplicar una función a cada imagen de una colección con map().
  • Calcular NDVI, EVI, NDMI y MNDWI para cada año.
  • Graficar el valor medio de los índices en el tiempo.
  • Mapear dónde cambió el EVI entre el primer y el último año.

Recursos #

  • Índices espectrales derivados de reflectancia de superficie (USGS)
  • ui.Chart.feature.byFeature()
  • ee.Image.reduceRegion()

Los índices de esta lección #

ÍndiceQué mideOrigen
NDVIVigor y densidad de la vegetaciónRouse et al. (1974)
EVIVigor en vegetación densa, sin saturarse tan rápidoHuete et al. (2002)
NDMIHumedad de la vegetaciónHardisky et al. (1983); Wilson y Sader (2002)
MNDWIPresencia de aguaXu (2006)

Los vimos en detalle en Índices de vegetación con Landsat 9 y en Detección de agua con Landsat 9. Aquí la novedad no son los índices, sino la forma de calcularlos: una sola función aplicada a toda la colección.

¿Por qué NDVI y EVI juntos? #

En bosques y cultivos muy densos, el NDVI se acerca a su máximo y deja de cambiar aunque la vegetación siga creciendo. Se dice que se satura. Huete y sus colaboradores diseñaron el EVI para reducir ese efecto. Si en tu gráfico el NDVI casi no se mueve pero el EVI sí, probablemente estás viendo vegetación densa donde el NDVI ya no distingue diferencias.

Paso 1: Construir la serie anual #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Partimos de la serie que construimos en Series de tiempo con Landsat: las mismas funciones, la misma unión de Landsat 4 a 9 y la misma mediana por año. Esta vez la empezamos en 2000.

// Factor de escala: convierte los valores digitales en reflectancia
function scaler(img) {
  var optical = img.select('SR_B.').multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select('ST_B.*').multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// Máscara de nubes con la banda QA_PIXEL
function mask_clouds(img) {
  var qa = img.select('QA_PIXEL');
  var cirrus = 1 << 2;       // bit 2, cirros
  var cloud = 1 << 3;        // bit 3, nubes
  var cloudShadow = 1 << 4;  // bit 4, sombra de nubes
  var snow = 1 << 5;         // bit 5, nieve
  var mask = qa.bitwiseAnd(cirrus).eq(0)
    .and(qa.bitwiseAnd(cloud).eq(0))
    .and(qa.bitwiseAnd(cloudShadow).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

// Parámetros de búsqueda
var startYear = 2000;   // año inicial
var endYear = 2025;     // año final
var startMonth = 1;     // mes inicial
var endMonth = 12;      // mes final
var cloudcover = 30;    // nubosidad máxima sobre tierra (%)

// Nombres comunes para las bandas de todos los sensores
var bandsTM = ['SR_B1', 'SR_B2', 'SR_B3', 'SR_B4', 'SR_B5', 'SR_B7'];   // Landsat 4, 5 y 7
var bandsOLI = ['SR_B2', 'SR_B3', 'SR_B4', 'SR_B5', 'SR_B6', 'SR_B7'];  // Landsat 8 y 9
var names = ['Blue', 'Green', 'Red', 'Nir', 'Swir1', 'Swir2'];

// Filtra una colección y prepara cada imagen
function landsat(id, bands) {
  return ee.ImageCollection(id)
    .filterBounds(AOI)
    .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01')
    .filter(ee.Filter.calendarRange(startMonth, endMonth, 'month'))
    .filter(ee.Filter.lte('CLOUD_COVER_LAND', cloudcover))
    .map(function (img) {
      return scaler(mask_clouds(img)).select(bands, names);
    });
}

// Landsat 4, 5, 7, 8 y 9 en una sola colección
var collection = landsat('LANDSAT/LT04/C02/T1_L2', bandsTM)
  .merge(landsat('LANDSAT/LT05/C02/T1_L2', bandsTM))
  .merge(landsat('LANDSAT/LE07/C02/T1_L2', bandsTM).filterDate('1999-04-15', '2013-05-30'))
  .merge(landsat('LANDSAT/LC08/C02/T1_L2', bandsOLI))
  .merge(landsat('LANDSAT/LC09/C02/T1_L2', bandsOLI));
print('Imágenes disponibles', collection.size());

// Una mediana por año
var years = ee.List.sequence(startYear, endYear);

var annual = ee.ImageCollection.fromImages(years.map(function (year) {
  var start = ee.Date.fromYMD(year, 1, 1);
  var images = collection.filterDate(start, start.advance(1, 'year'));
  return images.median()
    .clip(AOI)
    .set('year', year)
    .set('n_images', images.size());
}));

// Quitar los años sin imágenes
annual = annual.filter(ee.Filter.gt('n_images', 0));
print('Medianas anuales', annual);

Paso 2: Calcular los índices de cada año #

La función recibe una imagen anual y devuelve otra con cuatro bandas, una por índice. Usamos addBands() y luego select() en lugar de crear una imagen nueva, porque así la imagen conserva sus propiedades, incluido el año que necesitamos para el gráfico. Después aplicamos la función a toda la colección con map().

// Índices espectrales de cada imagen anual
function addIndices(img) {
  var ndvi = img.normalizedDifference(['Nir', 'Red']).rename('NDVI');
  var evi = img.expression(
    '2.5 * ((NIR - RED) / (NIR + 6 * RED - 7.5 * BLUE + 1))', {
      'NIR': img.select('Nir'),
      'RED': img.select('Red'),
      'BLUE': img.select('Blue')
    }).rename('EVI');
  var ndmi = img.normalizedDifference(['Nir', 'Swir1']).rename('NDMI');
  var mndwi = img.normalizedDifference(['Green', 'Swir1']).rename('MNDWI');
  // addBands conserva las propiedades de la imagen, incluido el año
  return img.addBands([ndvi, evi, ndmi, mndwi])
    .select(['NDVI', 'EVI', 'NDMI', 'MNDWI']);
}

var indices = annual.map(addIndices);
print('Índices por año', indices);

Paso 3: Visualizar el EVI de cada año #

Agregamos una capa de EVI por año, con la misma paleta de vegetación del curso básico.

// EVI de cada año
var vegPalette = {min: 0, max: 0.8, palette: ['DF923D', 'F1B555', 'FCD163', '99B718',
  '74A901', '529400', '3E8601', '207401', '056201', '004C00']};
Map.centerObject(AOI, 10);

indices.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = ee.Image(indices.filter(ee.Filter.eq('year', year)).first());
    Map.addLayer(img.select('EVI'), vegPalette, 'EVI ' + year, false);
  });
});

Paso 4: Graficar la evolución #

Para cada año calculamos el valor medio de cada índice dentro del AOI con reduceRegion() y guardamos el resultado en un Feature sin geometría. La colección de Features que resulta es una tabla, y ui.Chart.feature.byFeature() la dibuja con los años en el eje horizontal. Con bestEffort: true, Earth Engine aumenta el tamaño de píxel si el AOI es muy grande, para que el cálculo no falle.

// Valor medio de cada índice en el AOI, año por año
var stats = ee.FeatureCollection(indices.map(function (img) {
  var mean = img.reduceRegion({
    reducer: ee.Reducer.mean(),
    geometry: AOI,
    scale: 30,
    bestEffort: true,
    maxPixels: 1e10
  });
  return ee.Feature(null, mean).set('year', img.get('year'));
}));

var chart = ui.Chart.feature.byFeature(stats, 'year', ['NDVI', 'EVI'])
  .setChartType('LineChart')
  .setOptions({
    title: 'NDVI y EVI medios por año',
    hAxis: {title: 'Año', format: '####'},
    vAxis: {title: 'Valor del índice'},
    lineWidth: 2,
    pointSize: 4
  });
print(chart);

Cómo leer el gráfico. Una caída en un solo año puede deberse a una sequía, por ejemplo durante El Niño, a un incendio o a nubes que la máscara no quitó. Una caída que se mantiene varios años suele indicar un cambio de cobertura, como la deforestación. Activa las capas de esos años en el mapa para confirmar qué pasó.

Paso 5: Mapear el cambio #

Restamos el EVI del primer año al del último. Los tonos rojos marcan pérdida de vegetación, los verdes ganancia, y el blanco las zonas sin cambio.

// Cambio del EVI entre el primer y el último año
var first = ee.Image(indices.sort('year').first()).select('EVI');
var last = ee.Image(indices.sort('year', false).first()).select('EVI');
var change = last.subtract(first).rename('EVI_change');
Map.addLayer(change, {min: -0.3, max: 0.3, palette: ['d7191c', 'f7f7f7', '1a9641']}, 'Cambio de EVI');

Paso 6: Exportar los índices #

Exportamos una imagen por año con los cuatro índices como bandas.

// Una tarea de exportación por año
indices.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = ee.Image(indices.filter(ee.Filter.eq('year', year)).first());
    Export.image.toDrive({
      image: img.toFloat(),
      description: 'Indices_' + year,
      folder: 'Landsat_Index_Median',
      region: AOI,
      scale: 30,
      crs: 'EPSG:32618',  // UTM 18N, cámbiala por la zona de tu AOI
      maxPixels: 1e13
    });
  });
});

Conclusiones #

Con map() y una función, cualquier cálculo que hiciste sobre una imagen sirve para toda una serie. Puedes agregar a addIndices() otros índices del curso básico, como SAVI o NBR, y el resto del script seguirá funcionando igual. En la siguiente lección usaremos la misma idea para clasificar el agua de cada año con el método DSWE.
