Introducción #

Un índice calculado en una sola fecha muestra cómo está la vegetación en ese momento. Calculado año tras año, muestra tendencias: una zona que se deforesta, un humedal que se seca o un cultivo que se expande.

En esta lección calcularemos el EVI de cada mediana anual de Landsat. La función del índice viene de un módulo, un script aparte que guarda funciones para reutilizarlas en otros scripts.

Objetivos #

  • Cargar funciones de un módulo con require().
  • Aplicar una función a cada imagen de una colección con map().
  • Calcular el EVI para cada año de la serie.
  • Visualizar y exportar los índices.

Recursos #

  • Landsat Enhanced Vegetation Index (USGS)
  • Módulos y require() (guía de Earth Engine)

¿Por qué el EVI? #

En bosques y cultivos muy densos, el NDVI se acerca a su máximo y deja de cambiar aunque la vegetación siga creciendo. Se dice que se satura. Huete y sus colaboradores (2002) diseñaron el EVI para reducir ese efecto: corrige la influencia del suelo y de la atmósfera con las bandas roja y azul. Lo vimos en Índices de vegetación con Landsat 9.

Secciones 0 a 5: Construir la serie anual #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Las secciones 0 a 5 son las mismas de Series de tiempo con Landsat: funciones, bandas, unión de Landsat 4 a 9, parámetros, filtros y medianas anuales. Esta vez la serie empieza en 2020.

///////////////////////////////////////////////////////////////////////////////////
// 0 → CREAR FUNCIONES PRINCIPALES
///////////////////////////////////////////////////////////////////////////////////

// 0.1 → Función de factor de escala
function scaler (img) {
  var optical = img.select("SR_B.").multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select("ST_B.*").multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// 0.2 → Función de máscara de nubes
function mask_clouds (img) {
  // Banda de calidad QA_PIXEL (renombrada como BQA)
  var qa = img.select('BQA');
  // Bits de QA_PIXEL en Landsat Colección 2
  var cirrus = (1 << 2);              // bit 2: cirros
  var cloudsBitMask = (1 << 3);       // bit 3: nubes
  var cloudShadowBitMask = (1 << 4);  // bit 4: sombras de nubes
  var snow = (1 << 5);                // bit 5: nieve
  // Todos los bits deben estar en cero (condiciones despejadas)
  var mask = qa.bitwiseAnd(cloudShadowBitMask).eq(0)
    .and(qa.bitwiseAnd(cloudsBitMask).eq(0))
    .and(qa.bitwiseAnd(cirrus).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

var ls4 = ee.ImageCollection("LANDSAT/LT04/C02/T1_L2").map(scaler).select(bn5, bns);
var ls5 = ee.ImageCollection("LANDSAT/LT05/C02/T1_L2").map(scaler).select(bn5, bns);
var ls7 = ee.ImageCollection("LANDSAT/LE07/C02/T1_L2").map(scaler)
                            .filterDate('1999-04-15', '2013-05-30')
                            .select(bn7, bns);
var ls8 = ee.ImageCollection("LANDSAT/LC08/C02/T1_L2").map(scaler).select(bn8, bns);
var ls9 = ee.ImageCollection("LANDSAT/LC09/C02/T1_L2").map(scaler).select(bn9, bns);

var merged = ls4.merge(ls5).merge(ls7).merge(ls8).merge(ls9);

///////////////////////////////////////////////////////////////////////////////////

var startYear = 2020;  // Año inicio
var endYear = 2025;    // Año final
var startMonth = 1;    // Mes inicial
var endMonth = 12;     // Mes final
var cloudcover = 30;   // Cobertura de nubes (%)
var AOI = AOI;         // Área de estudio

///////////////////////////////////////////////////////////////////////////////////
// 4 → APLICAR FILTROS A LA COLECCIÓN FUSIONADA
///////////////////////////////////////////////////////////////////////////////////

var filtered = merged.filterDate(startYear + '-01-01', endYear + '-12-31')
                     .filter(ee.Filter.lte('CLOUD_COVER_LAND', cloudcover))
                     .filter(ee.Filter.calendarRange(startMonth, endMonth, 'month'))
                     .sort('system:time_start', false)
                     .filterBounds(AOI);

print("Imágenes disponibles para la zona de estudio (Landsat 4, 5, 7, 8 y 9)", filtered);

///////////////////////////////////////////////////////////////////////////////////
// 5 → CALCULAR MEDIANAS ANUALES
///////////////////////////////////////////////////////////////////////////////////

var years = ee.List.sequence(startYear, endYear);

function yearly_medians(year) {
  var start = ee.Date.fromYMD(year, 1, 1);
  var end = start.advance(1, 'year');
  var L = filtered.map(mask_clouds);
  var image = L.filterDate(start, end).median().clip(AOI).toFloat();
  return image.set('year', year);
}

// Generar medianas por año
var img_medians = years.map(yearly_medians);

// Remover imágenes vacías
img_medians = img_medians.map(function(ele) {
  var count = ee.Image(ele).bandNames().size();
  return ee.Algorithms.If(count.gt(0), ele, 0);
}).flatten();
img_medians = img_medians.removeAll([0]);

// Colección de medianas anuales
var colmeans = ee.ImageCollection(img_medians);
var años = ee.Array(colmeans.aggregate_array('year'));

print("Mediana de imágenes por año", colmeans);
print("Lista de años", años);

Sección 6: Calcular el índice de cada año #

El módulo LIST_EDUCAINDEX guarda la función EVI. La exporta con exports, y nuestro script la carga con require() en la variable x. Este es el fragmento del módulo que usamos:

// Módulo LIST_EDUCAINDEX (fragmento): función EVI
exports.EVI = function(image){
  return image.expression(
    '2.5 * ((NIR - RED) / (NIR + 6 * RED - 7.5 * BLUE + 1))', {
      'NIR': image.select(['Nir']),
      'RED': image.select(['Red']),
      'BLUE': image.select(['Blue'])
    }).rename('evi').toFloat();
};

Sobre el módulo. require() carga funciones guardadas en otro script del Code Editor, en este caso users/sigeduca/routines:Indexes/LIST_EDUCAINDEX. Si al ejecutar aparece un error de acceso, crea un script nuevo en tu propio repositorio, pega el código del módulo que mostramos aquí, guárdalo como LIST_EDUCAINDEX y cambia la ruta de require() por la tuya, por ejemplo users/TU_USUARIO/TU_REPOSITORIO:LIST_EDUCAINDEX.

XIndex() calcula el EVI de una imagen y le copia sus propiedades con copyProperties(), para que cada resultado conserve su año. copyProperties() devuelve un objeto genérico, por eso lo envolvemos en ee.Image(). Después aplicamos la función a toda la colección con map().

///////////////////////////////////////////////////////////////////////////////////
// 6 → CÁLCULO DE ÍNDICES ESPECTRALES
///////////////////////////////////////////////////////////////////////////////////

var x = require('users/sigeduca/routines:Indexes/LIST_EDUCAINDEX'); // MÓDULO DE EVI

// Crear función EVI
function XIndex (image){
  var INDEX = x.EVI(image);
  return ee.Image(INDEX.copyProperties(image));
}

var CalIndex = colmeans.map(XIndex);
print('Índices espectrales: ', CalIndex);

Conclusiones #

Con map() y una función, cualquier cálculo que hiciste sobre una imagen sirve para toda una serie. Y con un módulo, esa función se escribe una sola vez y se reutiliza en todos tus scripts. En la siguiente lección usaremos la misma idea para clasificar el agua de cada año con el método DSWE.

Referencias #
