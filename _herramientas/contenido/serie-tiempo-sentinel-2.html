Introducción #

Sentinel-2 tiene una historia más corta que Landsat, pero mucho más detalle. La Agencia Espacial Europea (ESA) lanzó Sentinel-2A en 2015 y Sentinel-2B en 2017. Juntos fotografían cada punto de la Tierra cada cinco días, con 10 m de resolución en las bandas visibles y en el infrarrojo cercano. Es la mejor opción para seguir cambios recientes en áreas pequeñas, como una finca, una ciénaga o el borde de una ciudad.

En esta lección crearemos una mediana anual sin nubes con la colección de reflectancia de superficie y exportaremos cada año a Google Drive.

Objetivos #

  • Filtrar la colección de Sentinel-2 por años, meses y nubosidad.
  • Crear una mediana anual sin nubes con la máscara SCL.
  • Mostrar y exportar cada año de la serie.
  • Entender por qué usamos la colección HARMONIZED en series de tiempo.

Recursos #

  • Sentinel-2 Surface Reflectance (COPERNICUS/S2_SR_HARMONIZED)
  • ee.ImageCollection.fromImages()

Dos detalles antes de empezar #

  • ¿Desde qué año? ESA genera la reflectancia de superficie (nivel 2A) de forma sistemática para todo el planeta desde diciembre de 2018. En años anteriores muchas zonas tienen pocas imágenes o ninguna, por eso empezamos la serie en 2019. Si tu zona tiene datos anteriores, puedes adelantar startYear, y el script descartará los años vacíos.
  • ¿Por qué HARMONIZED? Desde el 25 de enero de 2022, ESA suma 1000 a los valores de las imágenes nuevas por un cambio en su procesamiento. La colección S2_SR_HARMONIZED corrige ese desplazamiento para que las imágenes de antes y después de esa fecha sean comparables. En una serie de tiempo es indispensable: sin la corrección verías un salto falso en 2022.

Paso 1: Crear la función de máscara #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Usamos la misma función del curso básico. Oculta sombras, nubes y cirros con la banda SCL y pasa los valores a reflectancia, de 0 a 1.

// Máscara de nubes con la banda SCL y paso a reflectancia (0 a 1)
function maskS2clouds(img) {
  var scl = img.select('SCL');
  var mask = scl.neq(3)    // sombra de nubes
    .and(scl.neq(8))       // nubes, probabilidad media
    .and(scl.neq(9))       // nubes, probabilidad alta
    .and(scl.neq(10));     // cirros
  return img.updateMask(mask).select('B.*').divide(10000);
}

Paso 2: Parámetros y colección #

Filtramos por zona, años, meses y nubosidad, y aplicamos la máscara a cada imagen. Como Sentinel-2 pasa cada cinco días, un límite de 20 % de píxeles nubosos todavía deja muchas imágenes por año.

// Parámetros de búsqueda
var startYear = 2019;   // año inicial
var endYear = 2025;     // año final
var startMonth = 1;     // mes inicial
var endMonth = 12;      // mes final
var cloudcover = 20;    // porcentaje máximo de píxeles nubosos

// Colección filtrada y sin nubes
var collection = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
  .filterBounds(AOI)
  .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01')
  .filter(ee.Filter.calendarRange(startMonth, endMonth, 'month'))
  .filter(ee.Filter.lte('CLOUDY_PIXEL_PERCENTAGE', cloudcover))
  .map(maskS2clouds);
print('Imágenes disponibles', collection.size());

Paso 3: Crear una mediana por año #

El método es el mismo de Series de tiempo con Landsat: recorremos los años, calculamos una mediana para cada uno, guardamos el año y el número de imágenes, y eliminamos los años vacíos.

// Una mediana por año
var years = ee.List.sequence(startYear, endYear);

var annual = ee.ImageCollection.fromImages(years.map(function (year) {
  var start = ee.Date.fromYMD(year, 1, 1);
  var images = collection.filterDate(start, start.advance(1, 'year'));
  return images.median()
    .clip(AOI)
    .set('year', year)
    .set('n_images', images.size());
}));

// Quitar los años sin imágenes
annual = annual.filter(ee.Filter.gt('n_images', 0));
print('Medianas anuales', annual);

Paso 4: Visualizar la serie #

Agregamos una capa por año en color verdadero. Activa las capas una por una en el panel Layers para comparar los años.

// Color verdadero, una capa por año
var visRGB = {bands: ['B4', 'B3', 'B2'], min: 0.01, max: 0.22, gamma: 1};
Map.centerObject(AOI, 11);

annual.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = annual.filter(ee.Filter.eq('year', year)).first();
    Map.addLayer(img, visRGB, 'RGB ' + year, false);
  });
});

Paso 5: Exportar cada año #

Exportamos diez bandas a 10 m: las tres visibles, las tres del borde rojo, los dos infrarrojos cercanos (B8 y B8A) y los dos SWIR. Dejamos fuera B1 y B9, que sirven para medir aerosoles y vapor de agua en la atmósfera y tienen 60 m de resolución. Las bandas de 20 m se remuestrean a 10 m al exportar.

// Bandas a exportar: visibles, borde rojo, NIR y SWIR
var exportBands = ['B2', 'B3', 'B4', 'B5', 'B6', 'B7', 'B8', 'B8A', 'B11', 'B12'];

// Una tarea de exportación por año
annual.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = ee.Image(annual.filter(ee.Filter.eq('year', year)).first());
    Export.image.toDrive({
      image: img.select(exportBands).toFloat(),
      description: 'Sentinel2_mediana_' + year,
      folder: 'Sentinel_Median',
      region: AOI,
      scale: 10,
      crs: 'EPSG:32618',  // UTM 18N, cámbiala por la zona de tu AOI
      maxPixels: 1e13
    });
  });
});

Conclusiones #

Con Sentinel-2 tienes menos años que con Landsat, pero cada uno con 10 m de detalle. Elige Landsat cuando necesites mirar décadas atrás y Sentinel-2 cuando te interesen cambios recientes en áreas pequeñas.
