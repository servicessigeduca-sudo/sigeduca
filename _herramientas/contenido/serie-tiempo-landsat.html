Introducción #

Hasta ahora trabajamos con una imagen o con la mediana de unos pocos meses. En el nivel intermedio damos un paso más: usaremos colecciones completas para ver cómo cambia un lugar a lo largo de los años.

El programa Landsat es ideal para eso. Observa la Tierra desde 1972, y desde 1982, con Landsat 4, sus sensores miden la superficie con 30 m de resolución y bandas muy parecidas entre sí. Eso permite comparar una misma zona durante más de cuatro décadas. En esta lección uniremos Landsat 4, 5, 7, 8 y 9 en una sola colección y crearemos una mediana sin nubes para cada año.

Objetivos #

  • Unir las colecciones de Landsat 4, 5, 7, 8 y 9 con nombres de bandas comunes.
  • Recorrer una lista de años y crear una mediana anual sin nubes.
  • Eliminar los años que no tienen imágenes.
  • Mostrar y exportar cada año de la serie.

Recursos #

  • Productos de nivel 2 de Landsat Colección 2 (USGS)
  • Landsat 5 Surface Reflectance (LANDSAT/LT05/C02/T1_L2)
  • Landsat 8 Surface Reflectance (LANDSAT/LC08/C02/T1_L2)
  • ee.ImageCollection.fromImages()

Cinco satélites, una serie #

SatéliteSensorDatos en la serieDetalle
Landsat 4TM1982 a 1993Primer sensor TM, con 30 m y bandas SWIR.
Landsat 5TM1984 a 2012Operó casi 29 años, un récord Guinness.
Landsat 7ETM+1999 a 2013Desde 2003 sus escenas tienen franjas sin datos.
Landsat 8OLI2013 en adelanteMás sensibilidad radiométrica que TM y ETM+.
Landsat 9OLI-22021 en adelanteGemelo de Landsat 8. Juntos pasan cada 8 días.

Landsat 7 merece un comentario. El 31 de mayo de 2003 falló su corrector de líneas de escaneo (SLC), y desde entonces cada escena tiene franjas sin datos que suman cerca del 22 % de la imagen. En una mediana anual esas franjas se rellenan con otras fechas, así que el satélite sigue siendo útil. En el script lo usamos hasta mayo de 2013, cuando Landsat 8 empezó a entregar datos. Así cubrimos 2012, cuando Landsat 5 ya casi no tomaba imágenes y Landsat 8 todavía no estaba en órbita.

Mismas bandas, distinto número #

Landsat 8 y 9 agregaron una banda azul costera al inicio, y por eso las demás se corrieron un número. El azul es SR_B1 en Landsat 4, 5 y 7, pero SR_B2 en Landsat 8 y 9. Para unir las colecciones renombramos las bandas con select(), que recibe una lista con las bandas de entrada y otra con los nombres nuevos.

Los sensores no son idénticos. Las bandas de OLI son más estrechas que las de TM y ETM+, así que un mismo lugar puede dar valores un poco distintos con Landsat 7 y con Landsat 8. Para ver tendencias generales no es un problema. Para análisis cuantitativos finos, Roy et al. (2016) publicaron coeficientes para armonizar ambos sensores.

Paso 1: Crear las funciones #

El script usa una geometría llamada AOI. Dibújala con las herramientas de geometría del mapa en el Code Editor y renómbrala como AOI en el panel de importaciones.

Usamos las mismas funciones del curso básico. El factor de escala y los bits de QA_PIXEL son iguales en todos los Landsat de la Colección 2, así que sirven para los cinco satélites.

// Factor de escala: convierte los valores digitales en reflectancia
function scaler(img) {
  var optical = img.select('SR_B.').multiply(0.0000275).add(-0.2).toFloat();
  var thermal = img.select('ST_B.*').multiply(0.00341802).add(149).toFloat();
  return img.addBands(optical, null, true).addBands(thermal, null, true);
}

// Máscara de nubes con la banda QA_PIXEL
function mask_clouds(img) {
  var qa = img.select('QA_PIXEL');
  var cirrus = 1 << 2;       // bit 2, cirros
  var cloud = 1 << 3;        // bit 3, nubes
  var cloudShadow = 1 << 4;  // bit 4, sombra de nubes
  var snow = 1 << 5;         // bit 5, nieve
  var mask = qa.bitwiseAnd(cirrus).eq(0)
    .and(qa.bitwiseAnd(cloud).eq(0))
    .and(qa.bitwiseAnd(cloudShadow).eq(0))
    .and(qa.bitwiseAnd(snow).eq(0));
  return img.updateMask(mask);
}

Paso 2: Definir los parámetros #

Reunimos al inicio los valores que vas a cambiar. Con startMonth y endMonth puedes quedarte con una sola temporada, por ejemplo 1 y 3 para enero a marzo, la época seca en buena parte del Caribe colombiano. Comparar siempre la misma temporada evita confundir un cambio real con la diferencia entre la época seca y la de lluvias.

// Parámetros de búsqueda
var startYear = 1984;   // año inicial
var endYear = 2025;     // año final
var startMonth = 1;     // mes inicial
var endMonth = 12;      // mes final
var cloudcover = 30;    // nubosidad máxima sobre tierra (%)

Paso 3: Unir las colecciones #

La función landsat() filtra una colección por zona, fechas, meses y nubosidad, y después prepara cada imagen: aplica la máscara de nubes, el factor de escala y los nombres comunes. Filtrar antes de map() hace que Earth Engine procese solo las imágenes que necesitas. Al final unimos las cinco colecciones con merge().

// Nombres comunes para las bandas de todos los sensores
var bandsTM = ['SR_B1', 'SR_B2', 'SR_B3', 'SR_B4', 'SR_B5', 'SR_B7'];   // Landsat 4, 5 y 7
var bandsOLI = ['SR_B2', 'SR_B3', 'SR_B4', 'SR_B5', 'SR_B6', 'SR_B7'];  // Landsat 8 y 9
var names = ['Blue', 'Green', 'Red', 'Nir', 'Swir1', 'Swir2'];

// Filtra una colección y prepara cada imagen
function landsat(id, bands) {
  return ee.ImageCollection(id)
    .filterBounds(AOI)
    .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01')
    .filter(ee.Filter.calendarRange(startMonth, endMonth, 'month'))
    .filter(ee.Filter.lte('CLOUD_COVER_LAND', cloudcover))
    .map(function (img) {
      return scaler(mask_clouds(img)).select(bands, names);
    });
}

// Landsat 4, 5, 7, 8 y 9 en una sola colección
var collection = landsat('LANDSAT/LT04/C02/T1_L2', bandsTM)
  .merge(landsat('LANDSAT/LT05/C02/T1_L2', bandsTM))
  .merge(landsat('LANDSAT/LE07/C02/T1_L2', bandsTM).filterDate('1999-04-15', '2013-05-30'))
  .merge(landsat('LANDSAT/LC08/C02/T1_L2', bandsOLI))
  .merge(landsat('LANDSAT/LC09/C02/T1_L2', bandsOLI));
print('Imágenes disponibles', collection.size());

Paso 4: Crear una mediana por año #

Recorremos la lista de años con map(). Para cada año filtramos la colección, calculamos la mediana y guardamos el año como propiedad. También guardamos cuántas imágenes entraron en la mediana (n_images), y con ese dato eliminamos los años vacíos. En los primeros años del archivo puede no haber ninguna escena de tu zona.

// Una mediana por año
var years = ee.List.sequence(startYear, endYear);

var annual = ee.ImageCollection.fromImages(years.map(function (year) {
  var start = ee.Date.fromYMD(year, 1, 1);
  var images = collection.filterDate(start, start.advance(1, 'year'));
  return images.median()
    .clip(AOI)
    .set('year', year)
    .set('n_images', images.size());
}));

// Quitar los años sin imágenes
annual = annual.filter(ee.Filter.gt('n_images', 0));
print('Medianas anuales', annual);

Paso 5: Visualizar la serie #

aggregate_array('year') devuelve la lista de años que quedaron en la colección, y evaluate() la trae al navegador. Así podemos recorrerla con un ciclo normal de JavaScript y agregar una capa por año. Las capas se cargan apagadas: actívalas una por una en el panel Layers para ver cómo cambia tu zona.

// Color verdadero, una capa por año
var visRGB = {bands: ['Red', 'Green', 'Blue'], min: 0.002, max: 0.25, gamma: 1};
Map.centerObject(AOI, 10);

annual.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = annual.filter(ee.Filter.eq('year', year)).first();
    Map.addLayer(img, visRGB, 'RGB ' + year, false);
  });
});

Paso 6: Exportar cada año #

Cada año se exporta como una tarea independiente, así que en la pestaña Tasks verás una tarea por año y tendrás que ejecutar cada una. Indicamos crs para que todas salgan en la misma proyección. EPSG:32618 es UTM zona 18 Norte, que cubre buena parte de Colombia; cámbiala por la zona UTM de tu AOI.

// Una tarea de exportación por año
annual.aggregate_array('year').evaluate(function (list) {
  list.forEach(function (year) {
    var img = ee.Image(annual.filter(ee.Filter.eq('year', year)).first());
    Export.image.toDrive({
      image: img.toFloat(),
      description: 'Landsat_mediana_' + year,
      folder: 'Landsat_Median',
      region: AOI,
      scale: 30,
      crs: 'EPSG:32618',  // UTM 18N, cámbiala por la zona de tu AOI
      maxPixels: 1e13
    });
  });
});
