Introducción #

En este taller aprenderemos a trabajar con shapefiles en Google Earth Engine (GEE). Los shapefiles son conjuntos de entidades geoespaciales que pueden usarse para análisis y visualización en GEE. Exploraremos cómo filtrarlos, visualizarlos en un mapa y realizar análisis espaciales básicos.

Objetivos #

  • Aprender a filtrar shapefiles utilizando filter y filterMetadata.
  • Visualizar shapefiles en un mapa interactivo.
  • Comprender cómo realizar análisis espaciales básicos utilizando las Feature Collections.

Shapefiles en Google Earth Engine #

Los shapefiles en GEE son conjuntos de entidades geoespaciales que representan objetos del mundo real, como países, ciudades, cuerpos de agua o parcelas agrícolas. Estas colecciones están compuestas por características geométricas y atributos asociados que describen cada entidad de manera única.

  • Cada elemento de una Feature Collection representa una entidad, como un punto, una línea o un polígono, con una localización geográfica específica. A eso lo llamamos entidad geoespacial.
  • Además de su geometría, cada entidad puede tener atributos numéricos, categóricos o de texto, desde la población de una ciudad hasta el nombre de un país.
  • Las colecciones pueden contener desde unas pocas hasta millones de entidades, así que escalan muy bien para análisis grandes.

Función filter #

La función filter permite filtrar una Feature Collection utilizando una condición específica. Su sintaxis general es la siguiente.

var nuevaColeccion = featureCollection.filter(ee.Filter.operador(atributo, valor));
  • featureCollection es la colección que queremos filtrar.
  • atributo es el nombre del campo sobre el que aplicamos la condición.
  • operador define el tipo de comparación.
  • valor es aquello con lo que comparamos el atributo.

Estos son los operadores que más vas a usar.

OperadorSelecciona entidades donde el atributo…
ee.Filter.eqes igual a un valor
ee.Filter.gtes mayor que un valor
ee.Filter.ltes menor que un valor

Función filterMetadata #

La función filterMetadata permite filtrar una Feature Collection usando los metadatos asociados a las entidades. Su sintaxis general es la siguiente.

var nuevaColeccion = featureCollection.filterMetadata(nombreMetadato, operador, valor);
  • featureCollection es la colección que queremos filtrar.
  • nombreMetadato es el nombre del metadato que usamos para filtrar.
  • operador define el tipo de comparación.
  • valor es aquello con lo que comparamos el metadato.

Estos son los operadores que más vas a usar.

OperadorSelecciona entidades donde el metadato…
"equals"es igual a un valor
"greater_than"es mayor que un valor
"less_than"es menor que un valor

Recursos #

  • Más límites administrativos en el catálogo de Earth Engine

Paso 1: Filtrar con filter #

Con filter nos quedamos solo con Colombia dentro de la colección de países.

// Cargar la Feature Collection de países
var Countries = ee.FeatureCollection("FAO/GAUL/2015/level0");

// Filtrar la Feature Collection para obtener solo Colombia
var Colombia = Countries.filter(ee.Filter.eq("ADM0_NAME", "Colombia"));

La condición de igualdad se aplica al atributo ADM0_NAME (nombre del país), que debe ser igual a "Colombia", y el resultado es una nueva colección que contiene solo ese país.

Paso 2: Filtrar con filterMetadata #

Con filterMetadata hacemos lo mismo con la colección de ciudades para quedarnos con Bogotá.

// Cargar la Feature Collection de ciudades
var cities = ee.FeatureCollection("FAO/GAUL_SIMPLIFIED_500m/2015/level2");

// Filtrar la Feature Collection para obtener solo Bogotá
var Bogota = cities.filterMetadata("ADM2_NAME", "equals", "Santafe De Bogota D.c.");

La condición se aplica al metadato ADM2_NAME (nombre de la ciudad), que debe ser igual a "Santafe De Bogota D.c.", así que el resultado contiene solo Bogotá.

Paso 3: Visualizar en el mapa #

Una vez filtrados, mostramos los shapefiles en el mapa con Map.addLayer, cuya sintaxis general es esta.

Map.addLayer(eeObject, visParams, name, shown);
  • eeObject es el objeto que queremos ver, ya sea una Image, una FeatureCollection, una Geometry u otro.
  • visParams reúne los parámetros de visualización, como el color, la opacidad o la escala.
  • name es el nombre que aparece en el panel de capas.
  • shown vale true o false e indica si la capa se ve al cargar el mapa.

Así queda aplicado a nuestras capas.

// Centrar el mapa en Colombia
Map.centerObject(Colombia, 5);

// Añadir los shapefiles al mapa
Map.addLayer(Colombia, {color: "red"}, "Colombia", true);

// Añadir Bogotá al mapa
Map.addLayer(Bogota, {color: "white"}, "Bogotá", true);
